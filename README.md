# Breathwork Box 4-7-8 Visualizer

Guided breathing app with three patterns: Box (4-4-4-4), 4-7-8, and Wim Hof (30-cycle + breath hold).
An animated circle expands and contracts with color transitions (blue=inhale, purple=hold, green=exhale) and phase countdown timers.
Sessions are logged with date, pattern, and duration in localStorage (`breathwork_log`).
